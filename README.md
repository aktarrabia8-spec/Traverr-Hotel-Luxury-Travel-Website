# 🏨 Traverr Hotel – Luxury Travel Website

Traverr Hotel, kullanıcıların otel hizmetlerini, seyahat destinasyonlarını ve konaklama seçeneklerini inceleyebilmesi amacıyla tasarlanmış modern bir otel ve seyahat web sitesi arayüzüdür. Proje, HTML5, CSS3 ve Bootstrap kullanılarak geliştirilmiş olup görsel tasarım, sayfa düzeni ve responsive web tasarımı konularına odaklanmaktadır.

## 📌 Proje Hakkında

Bu projede, bir otelin dijital ortamda tanıtılmasını sağlayan kullanıcı dostu bir web arayüzü oluşturulmuştur. Ziyaretçilerin otel hakkında bilgi edinebileceği, sunulan hizmetleri inceleyebileceği, popüler seyahat noktalarını keşfedebileceği ve iletişim alanına ulaşabileceği bir sayfa yapısı hazırlanmıştır.

Projenin temel amacı; HTML ile sayfa yapısı oluşturma, CSS ile tasarım geliştirme ve Bootstrap bileşenlerini kullanarak düzenli, modern ve farklı ekran boyutlarına uyum sağlayan bir web arayüzü geliştirme becerilerini uygulamaktır.

## ✨ Özellikler

- **Responsive Tasarım:** Farklı ekran boyutlarına uyum sağlamayı amaçlayan sayfa düzeni.
- **Navigasyon Menüsü:** Sayfa bölümleri arasında kolay geçiş sağlayan menü yapısı.
- **Hero Alanı:** Görsel açıdan dikkat çekici, büyük başlık ve görsel alanı.
- **Bootstrap Carousel:** Görseller arasında geçiş yapmayı sağlayan slider bileşeni.
- **Otel Arama Formu:** Konaklama ve rezervasyon arayüzünü temsil eden form alanı.
- **Hakkımızda Bölümü:** Otel ve hizmetleri hakkında tanıtıcı içerikler.
- **Hizmetler Bölümü:** Sunulan hizmetlerin görsel ve metinsel olarak tanıtılması.
- **Destinasyonlar:** Seyahat edilebilecek yerlerin tanıtıldığı kart yapıları.
- **Müşteri Yorumları:** Kullanıcı deneyimlerini göstermek için tasarlanan yorum alanı.
- **Ekip Bölümü:** Ekip üyelerini tanıtan görsel alanlar.
- **Footer:** İletişim ve ek bağlantılar için sayfanın alt bölümü.
- **Font Awesome İkonları:** Arayüzde ikon kullanımı.

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Kullanım Amacı |
|---|---|
| HTML5 | Web sayfasının yapısını oluşturmak |
| CSS3 | Renk, boyut, yerleşim ve görsel tasarımı düzenlemek |
| Bootstrap 5.3.8 | Grid sistemi, responsive düzen ve hazır bileşenler |
| Font Awesome 6.5.1 | İkonları sayfaya eklemek |
| JavaScript | Bootstrap bileşenlerinin etkileşimli davranışlarını desteklemek |

## 📂 Proje Yapısı

Projedeki klasörler aşağıdaki örnek yapıya göre düzenlenebilir. Dosya ve klasör adlarını kendi projenle eşleştirmen gerekir.

```text
Traverr-Hotel/
│
├── index.html
├── css/
│   ├── style.css
│   └── responsive.css
│
├── img/
│   └── ...
│
└── README.md
```

- `index.html`: Web sayfasının HTML yapısını içerir.
- `css/style.css`: Genel tasarım ve sayfa stillerini içerir.
- `css/responsive.css`: Farklı ekran boyutlarına yönelik CSS düzenlemelerini içerir.
- `img/`: Projede kullanılan görselleri barındırır.
- `README.md`: Projenin açıklamasını ve kullanım bilgilerini içerir.

## 🧩 Sayfa Bölümleri

### 1. Header ve Navigasyon
Kullanıcının sayfada gezinmesini sağlayan üst alan ve menü bağlantıları bulunur.

### 2. Hero ve Slider
Büyük görseller ve tanıtım metinleriyle ziyaretçinin dikkatini çekmek için tasarlanmıştır. Bootstrap Carousel kullanılarak görseller arasında geçiş yapılabilir.

### 3. Otel Arama Alanı
Giriş tarihi, çıkış tarihi ve diğer konaklama bilgileri için form arayüzü sunar. Gerçek rezervasyon işlemleri için ayrıca bir backend veya rezervasyon servisi gerekir.

### 4. About Us
Otelin genel tanıtımını, hizmet anlayışını ve öne çıkan bilgilerini sunar.

### 5. Hizmetler
Otelin sunduğu hizmetlerin kullanıcıya anlaşılır ve görsel açıdan düzenli biçimde gösterilmesini sağlar.

### 6. Destinasyonlar
Seyahat noktalarını görseller ve kısa açıklamalarla tanıtan bir bölüm içerir.

### 7. Müşteri Yorumları
Müşteri deneyimlerini ve yorumlarını göstermek için hazırlanmış carousel alanıdır.

### 8. Ekip ve Footer
Ekip üyelerinin tanıtılmasına ve sayfanın alt kısmında ek bağlantıların sunulmasına olanak tanır.

## 🚀 Kurulum ve Çalıştırma

Projeyi bilgisayarında çalıştırmak için aşağıdaki adımları izleyebilirsin:

1. GitHub deposunu bilgisayarına indir veya projeyi ZIP olarak indir.
2. İndirilen klasörü Visual Studio Code ile aç.
3. `index.html` dosyasını bul.
4. Dosyayı tarayıcıda aç veya Visual Studio Code üzerinde Live Server eklentisini kullan.
5. Sayfanın farklı ekran boyutlarındaki görünümünü kontrol et.

Proje statik bir web arayüzü olarak çalıştırılabilir. Bunun için zorunlu bir paket yöneticisi kurulumu gerekmez; ancak kullanılan kütüphanelerin bağlantılarının erişilebilir olması gerekir.

## 📱 Responsive Tasarım

Projenin farklı cihazlarda daha kullanışlı görünmesi için CSS medya sorguları ve Bootstrap grid sistemi kullanılabilir. Masaüstü, tablet ve mobil ekranlarda içeriklerin taşmaması, görsellerin uygun boyutlarda görüntülenmesi ve navigasyonun kullanılabilir olması hedeflenir.
